# comTexto — Frontend (MVP)

Interface simples para consumo da API Dialetus.

---

## 🎯 Objetivo

Permitir que o usuário:

- digite um texto
- escolha um modo de tradução
- visualize o resultado retornado pela API

---

## 🚀 Como rodar

Abra o arquivo:

```
index.html
```

diretamente no navegador.

---

## 🔌 Dependência

Este frontend depende da API Dialetus rodando localmente.

URL padrão configurada:

```
http://localhost:8080/translate
```

Se a API estiver em outra porta ou host, ajuste a URL no código JavaScript.

---

## 🧭 Fluxo de uso

1. Digite um texto
2. Escolha o modo de tradução
3. Clique em **Traduzir**
4. Veja o resultado em **Saiu assim**

---

## 🎛️ Modos disponíveis

- Corporativês
- Butequês
- LinkedInês

> Os valores enviados para a API seguem o padrão definido no backend.
